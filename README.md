# 할일 알람

알람이 울리면 **할일이 화면 가득 엄청 크게** 보이는 휴대폰용 알람 웹앱입니다.

- 알람마다 시간 + 할일 + 반복 요일 설정
- 울릴 때: 검은/빨간 깜빡임 배경 위에 노란 글씨로 할일을 화면 크기에 맞게 최대한 크게 표시
- `✔ 완료 · 끄기` / `5분 뒤 다시` 큰 버튼
- 삐삐 소리 + 진동(안드로이드), 화면 꺼짐 방지(Wake Lock)
- 휴대폰에 저장(localStorage), 홈 화면에 추가하면 앱처럼 실행(PWA)

## 사용법

1. `index.html`을 웹에 올립니다 (예: GitHub 저장소 Settings → Pages → 브랜치 선택).
2. 휴대폰 브라우저로 열고 **홈 화면에 추가**합니다.
3. 앱에서 `🔔 알람 소리 켜기`를 한 번 누르고, `＋`로 알람을 추가합니다.
4. 알람 시간까지 **앱을 열어둔 채** 두세요 (화면은 켜진 상태로 유지됩니다).

## 한계

웹앱이라 브라우저가 완전히 닫히거나 폰이 잠겨 있으면 정해진 시간에 깨울 수 없습니다.
자기 전 앱을 켜두고 충전기에 꽂아두는 방식으로 쓰세요.
